Test the USB cable and board

Plug the purifier's small circuit board into the laptop with its USB cable. Then click the button and pick the item that says CP210x, USB to UART, CH340 or COM…, and click Connect in that box.

The list is empty? Open the matching guide, then click the button again:

Windows: install the USB driver
  1. Keep the board plugged in. Press the Windows key, type Device Manager, open it.
  2. Under Other devices look for CP2102 USB to UART Bridge Controller (or “Unknown device”) with a yellow ⚠. (If it's under Ports (COM & LPT) as Silicon Labs CP210x, the driver is fine, so try another USB cable or port.)
  3. Download “CP210x Universal Windows Driver” and right-click it → Extract All.
  4. Back in Device Manager: right-click the ⚠ item → Update driver → Browse my computer for drivers → pick the extracted folder → Next.
  5. Unplug and re-plug the board, then click Test the USB connection again.
  6. If the board says CH340, use the CH340 driver instead.
Mac
  1. Most Macs need no driver. Try another USB cable (some only charge) and plug it straight into the Mac (use an adapter, not a hub, for USB-C).
  2. If the board says CH340, install the CH340 driver, restart the Mac and try again.
Any laptop
  1. Try a different USB cable (the one that came with the board if possible) and a different USB port directly on the laptop.
  2. Close Arduino IDE and any other page or program that uses the purifier.
