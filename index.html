Windows laptop: does it need a driver?
  1. Plug the purifier's small board into the laptop.
  2. Press the Windows key, type Device Manager and open it.
  3. Look for CP2102 USB to UART Bridge Controller (or “Unknown device”) with a yellow ⚠ under Other devices. If you see Silicon Labs CP210x … (COM3) under Ports (COM & LPT), the driver is already fine.
  4. If there's a ⚠: download “CP210x Universal Windows Driver”, right-click the downloaded file → Extract All.
  5. In Device Manager right-click the ⚠ item → Update driver → Browse my computer for drivers → pick the extracted folder → Next. Unplug and re-plug the board.
  6. If the board says CH340 instead, use the CH340 driver.

1 Connect the purifier

Plug the purifier's small circuit board into this laptop with the USB cable. Then click Connect and pick the item that says CP210x, USB to UART, CH340 or COM…, then click Connect in that box.

Nothing in the list? (1) Try another USB cable, some only charge. (2) Try another USB port, directly on the laptop. (3) On Windows open the driver guide at the top of this page. (4) Close Arduino IDE or any other page that uses the purifier.

“Failed to connect”? Press and hold the BOOT button on the board, click Connect again, and let go once it says connected. (If the button can't be reached, just try again, the page also retries by itself at slower speeds.)

2 Save a backup

Saves the purifier's current software to this laptop first, so nothing can be lost. Takes 1–7 minutes depending on the connection speed. Keep the backup file.

3 Install the new software

About 1 minute. Don't unplug while the bar is moving.

4 Check the screen

Look at the purifier's screen now.

It should show the words SCREEN TEST on a black background, with three boxes: RED, GREEN, BLUE. Which one is true?

5 Connect to home WiFi

The purifier only works with 2.4 GHz WiFi (not 5 GHz). Phone hotspot: iPhone → turn on “Maximise Compatibility”; Android → set the band to 2.4 GHz; keep the hotspot screen open while it connects.

6 Finished

Last step

  1. Unplug the USB cable.
  2. Power the purifier the normal way (its own power adapter).
  3. After about 10 seconds the screen shows the air reading. A few seconds later the fan starts and speeds up slowly. That is normal.
  4. If the screen ever goes white or the purifier restarts by itself, tell Nikhil. It means the power adapter is weak. The software already protects the purifier by limiting the fan.
